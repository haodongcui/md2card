# Md2Card 排版展示

这是一份面向技术内容的 Markdown 卡片样张。它把标题、正文、公式、表格、图片和代码放进同一条阅读路径，用于展示一篇笔记在连续图片卡片中的层级、节奏与留白。

## 标题、正文与行内元素

二级标题开启一个完整主题，正文则承担解释与过渡。即使同一段里混有 English terms、**加粗强调**、*斜体补充*、~~删除线~~、[参考链接](https://github.com/haodongcui/md2card) 与 `inline_code()`，文字仍应保持稳定的阅读节奏。

行内公式适合嵌入说明之中，例如信噪比可以写作 $\mathrm{SNR}=10\log_{10}(P_s/P_n)$；它更像一个自然的术语，不应把整段正文压缩得局促。必要时，用短引用突出一个结论，也能让读者在连续内容中获得停顿。

> 先建立清晰的标题层级，再用正文、强调和引用安排阅读重心。一张卡片不必塞满信息，留出呼吸感同样重要。

### 三级标题与短列表

- **正文**：说明概念、连接上下文；
- **标题**：建立章节与子主题的层级；
- **行内元素**：保留变量、来源与重点；
- **引用块**：承接结论、提醒或原文摘录。

## 公式排版展示

以扩散模型的“一步加噪”原理为例，展示公式由一句说明引出，读者无需先阅读长篇背景，也能把符号和关系对应起来：

$$
x_t = \sqrt{\bar\alpha_t}\,x_0
+ \sqrt{1-\bar\alpha_t}\,\epsilon,
\qquad \epsilon\sim\mathcal{N}(0,I).
$$

其中 $x_0$ 表示原始样本，$x_t$ 表示第 $t$ 步的带噪样本，$\bar\alpha_t$ 控制信号保留比例。展示公式应保有足够的上下空间，并和解释文字紧密相连。

多行推导同样可以保持清晰的对齐关系。下面的写法适合展示两个互相关联的量：

$$
\begin{aligned}
\mathcal{L}_{\mathrm{simple}}(\theta)
&= \mathbb{E}_{t,x_0,\epsilon}\left[
\left\lVert \epsilon - \epsilon_\theta(x_t,t) \right\rVert_2^2
\right],\\
\operatorname{SNR}(t)
&= \frac{\bar\alpha_t}{1-\bar\alpha_t}.
\end{aligned}
$$

公式较长时，缩放只应影响公式本身，普通正文的字号和宽度仍然维持原样。

## 表格与图片混排

表格适合收纳需要横向比较的信息。例如，下表把同一个例子中的关键符号集中在一起，读者可以快速查找而无需回到前文。

| 符号 | 含义 | 阅读提示 |
| --- | --- | --- |
| $x_0$ | 原始样本 | 最终希望恢复的内容 |
| $x_t$ | 带噪样本 | 当前仍保留的信号 |
| $\epsilon$ | 随机噪声 | 网络的预测目标 |
| $\beta_t$ | 噪声日程 | 每一步变化的幅度 |

表 1：紧随表格的表注会自动与表格组成同一个阅读单元，不会单独落到下一张卡片。

## 代码、引用与步骤

短代码块适合保留可复查的实现线索。下面以同一条公式为背景，展示简洁的 Python 片段：

```python
def add_noise(x0, alpha_bar, noise):
    signal = alpha_bar.sqrt() * x0
    random_part = (1 - alpha_bar).sqrt() * noise
    return signal + random_part
```

代码中的等宽字体、行距和背景应与正文区分开，但不应过度抢眼。接着，用有序列表呈现一个轻量的阅读顺序：

1. 用标题给出主题和方向；
2. 用短段落解释必要的背景；
3. 用公式、表格或图片承载结构化信息；
4. 用代码留下可以追溯的实现细节。

如果内容同时涉及配置与实现，也可以加入一段 TypeScript：

```typescript
const card = {
  title: "公式排版展示",
  density: "balanced",
  content: ["text", "math", "table", "image"],
} as const;
```

## 宽图与连续卡片

注意力矩阵、实验曲线和模型结构图通常比正文更宽。它们应在自己的边界里完整呈现，正常文字仍维持舒适的阅读宽度。

![宽幅注意力矩阵示意](./images/wide-matrix.svg "图 3 · 宽图承载结构性信息，独立适配卡片宽度，并与前后文本保持自然间距")

一篇技术内容不必为了适应图片而牺牲文字，也不必为了塞进单张卡片而把公式和表格缩得难以阅读。让不同类型的信息各自拥有合适的尺寸，再由稳定的分页把它们串成连续的阅读体验，这就是这份样张想呈现的效果。
