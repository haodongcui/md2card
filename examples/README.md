# 示例文章

这里的示例不是截图素材，而是一篇可以直接导入 `md2card` 的完整 Markdown 文章。它同时是人工验收样稿：每次调整解析、分页、图片绑定或导出逻辑时，都应使用它检查真实卡片效果。

## `complex-markdown/`

| 文件 | 用途 |
| --- | --- |
| [`复杂排版与资源回归样例.md`](./complex-markdown/复杂排版与资源回归样例.md) | 完整产品演示，覆盖标题、正文、引用、图片、公式、表格、代码、列表、链接与显式分页 |
| `images/architecture.svg` | 架构与本地图片路径绑定 |
| `images/sampling-pipeline.svg` | 多图、图注与流程图布局 |
| `images/wide-matrix.svg` | 宽幅图片在卡片安全区内的缩放 |

### 导入方式

1. 在工作台选择“导入 Markdown”，打开 `复杂排版与资源回归样例.md`；也可以直接拖入该文件。
2. 出现图片附件提示后，选择 `complex-markdown` 目录，或打开“管理图片”并点击“自动补齐（选择图片所在文件夹）”。
3. 三张 SVG 应显示为已绑定。建议分别试用 3:4 / 2:3、不同密度和不同卡片主题，再导出一次标准 PNG ZIP。

### 建议检查

- [x] 首个 H1 被用作文章名与首卡标题，不在正文重复。
- [x] 三张本地 SVG 均按相对路径正确绑定，图片与图注不分离。
- [x] H2 / H3 不会孤立停在页尾；显式分页从指定位置开始新卡。
- [x] 行内公式、展示公式和长数学符号能够正常渲染。
- [x] 宽表格、长表格、代码块和长 URL 不裁切；续页保持阅读上下文。
- [x] 预览与导出的页序、主题和版式一致。
